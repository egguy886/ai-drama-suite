# AI 短剧生产编排（工业实战增强版）

把创意变成一条可追溯的工业级生产链：导演判断 → 资产/声线 → 空间调度 → 镜头/光线/动作 → 不可变台词 → 提示词编译 → 实际画面 QC。

这是**控制合同层**，不重写既有导演或资产方法：

- 剧本解读、视觉概念、节拍/镜头归并、台词时序、剪辑动机与可生成性，按 `references/independent-production-core.md` 在本包内完成。
- 人物、场景、道具的真实外观、状态与审核，按本包内置资产合同完成。
- 角色声线、不可变台词与音频分轨隔离，按本包内置音频合同完成。
- 类型色彩、镜头偏好与材质参数，按本包内置类型适配表完成。

本 Skill 把这些已批准的决定变成本包内可传递、检查和回写的控制合同。

## 1. 先判断输入，补齐缺口

从用户输入提取：受众/时长、剧本形态、人物目标与阻力、场景、主类型、目标平台、已有关联资产、专属声线 WAV 或草图。缺失项写为 `pending`，不可用空泛的“爆款”“电影感”代填。大纲、草图或口述造成的补充事实必须写 `assumed`，不可伪装为原始设定。

| 输入状态 | 首要产物 | 本包处理层 |
|---|---|---|
| 只有故事点子 | `narrative_beat_contract` | 导演与剧本层 |
| 角色/场景尚未固定 | Cxx/Sxx/Pxx 资产合同 | 本包资产层 |
| 角色发声但音色易变 | `voice_anchor_contract` | 本包音频资产层 |
| 对白容易被 AI 篡改 | `immutable_dialogue_ledger` | 本包台词门禁层 |
| 已有资产，画面易漂移 | `blocking_map` | 本包镜头层 |
| 已有草图或分镜草稿 | `sketch_to_shot_brief` | 镜头与提示词层 |
| 对打、追逐、抢夺 | `action_ledger` | 镜头、提示词与成片检查层 |
| 画面“平”“假”“不高级” | `lighting_plan` | 镜头、提示词与成片检查层 |

## 2. 使用固定的生产顺序

1. 先按本包内置导演判断完成剧本三层读法、视觉概念与场策略；再从其判断结果写可检验的开场钩子、目标/阻力、策略或权力转折、结尾钩子。
2. 按本包内置资产合同建立 Cxx/Sxx/Pxx 与专属声线资产库（`voice_anchor_contract`）；先人工审核，再进入分镜。不要以视频抽卡替代资产库。
3. 锁定剧本不可变台词台账（`immutable_dialogue_ledger`），核算语速秒数并验证可见口型，严禁后续编译中擅自改写或删词。
4. 对每镜建立 `blocking_map`：空间锚点、人物位置/朝向/高度、道具位置、视线、摄影机和安全活动区必须能画在同一张平面图上。
5. 用本包类型适配层提供镜头、色彩和材质参数；类型参数不得改变审核过的资产外观。
6. 仅在需要时叠加专项合同：草图转镜头、布光、打戏动作账本。详细字段见 [control-contracts.md](references/control-contracts.md)。
7. 本包提示词编译层把所有合同装进既有六大模块外层与数字10信息内核：
   - 强制将配乐隔离为 `non_diegetic_music: SILENT`；
   - 现场物理动量与环境音效写入 `overall_soundscape`；
   - 角色出场发声严格绑定 `<Audio N>` ➔ `ref_audio_N`；
   - 逐字台词严格写入 `<d>[Language] ...</d>`。
8. 串行咬合接力：段 N 验收后，取结尾前 `0.35s` 稳定尾帧作为段 N+1 的 `<Picture 1>`。
9. 本包成片检查层用实际画面复核，不以平台任务成功、漂亮单帧或重复生成当作通过。

## 3. 九大约束性控制合同（工业实战扩展版）

### 3.1 剧本节拍合同
写 `hook / want / obstacle / strategy_shift / power_turn / cost / cliffhanger`，并记录观众信息差、人物进出状态差、情绪曲线与视觉概念引用。每项必须是画面或台词可观察的事实。

### 3.2 视觉资产库合同（含资产分级绑定与局部法线死锁）★
资产库（`asset_registry`）是已批准 Cxx/Sxx/Pxx 的索引。每个条目至少有：`asset_id`、版本、状态、参考图、锁定特征、可变状态、来源镜头、最后审阅日期。版本变化使用后缀（如 `C01b`），绝不覆盖已批准版本。
- **资产粒度分级死锁 (Asset Granularity Tiering)**：特写、微距镜头（如手掌掌心、面部局部、异变伤痕、手持小道具）**严禁混用全身立绘作为参考图**，必须建立并绑定专属局部资产卡（如 `Prop_Lucas_Dragonfire_Palm.png`），避免全身立绘导致扩散模型脑补全身变异（如手背长出恶魔裂纹）。
- **局部拍摄法线与未异变区域约束**：提示词中必须显式锁死拍摄法线（例如正对内侧凹陷掌心），并严加排他负向（手腕与小臂为正常人类皮肤，绝无熔岩裂纹）。

### 3.3 声线锚定资产系统（Voice Anchor Binding）★
引入项目自建的 `VoxCPM2_EN/normalized/` 音频锁体系。当跟踪主角（如 Lucas、Elara、Kaiser、Grover 等）出场并有台词时，必须绑定实物标准 WAV 文件，并在提示词中指派专属标签（如 `<Audio 1>`），API 载荷中映射为 `ref_audio_0`。全剧角色音色绝对连续，严禁跨段漂移或依赖 AI 随机嗓音。

### 3.4 配乐静音隔离协议（non_diegetic_music: SILENT）★
为了保证分段视频后期剪辑的绝对连贯，**强制将视频生成模型的配乐参数设为 SILENT**。AI 视频模型仅负责生成现场物理音效与环境声（`overall_soundscape`：暴雨、踩脚、喘息、机甲轰鸣、碰撞），禁止生成背景音乐。背景配乐由剪辑师在剪辑台进行全局混音通铺，彻底杜绝切镜时的断崖式跳音刺耳。

### 3.5 不可变台词防篡改台账（Immutable Dialogue Ledger）★
锁定剧本原始台词，建立不可变台账。提示词中的对白必须与剧本原文 100% 逐字匹配，严格保留原始语言与标点，封装于 `<d>[Language] ...</d>` 中。严禁 AI 擅自扩写、润色、意译或删减剧本对白。
- **发声主控与同画幅非发声者闭嘴死锁 (Speaker-Facing & Muzzle Lock)**：说话角色面部/嘴部必须占据当前微时序主视觉机位；同画框内非说话角色必须在提示词与负向中显式声明：`[角色名] lips tightly pressed shut with zero mouth movement, silent listener`（嘴唇紧抿，零嘴部动作，完全安静倾听），彻底杜绝声音夺舍与张冠李戴。
- **视听因果递进防先知 (Timeline Causality Protocol)**：严格遵守“先动作 ➔ 后视线 ➔ 再发问”因果铁律。次角色必须在上一微时序亲眼看见道具并产生神情反应后，才能在下一时序开口发问，严禁未卜先知。

### 3.6 场面调度图（blocking_map · Higgsfield 空间锚定增强）
每张图必须完成 4 项刚性空间锁定：
1. **2D 屏幕绝对坐标**：明确主体位于 `screen-left foreground`、`screen-center midground` 或 `screen-right background`，禁止使用模糊的“在身旁/背后”。
2. **刚性几何地标锚定（Rigid Geometric Anchors）**：主场景必须选定 1~2 个不动的物理刚体（如直径 2 米的铸铁排风机、30cm 高的花岗岩石阶、固定的龙骨立柱），作为深度与遮挡计算的几何基准，彻底消除跨镜头背景漂移。
3. **第 0 秒实体常驻刚体法则 (Anchor Zero Rule · Anti-Spawning)**：凡是在镜头中途被捡起、触碰或交互的道具，必须自 `00:00.000`（首帧）起即作为客观物理刚体声明半埋或放置在场景绝对坐标中，严禁中途虚空生成道具。
4. **接触面物理粘合**：鞋靴必须牢牢咬死地面（`zero foot sliding / zero air-walking`），武器握持刚性贴合。调度先于机位。

### 3.7 布光图（lighting_plan）
每镜列出主光、补光、轮廓/背景光的画内来源、方向、色温、强度或光比及照亮区域，并记录开镜/尾帧是否连续。

### 3.8 动作账本（action_ledger · 动作状态机与换装跳切）
打戏与身体接触拆为可生成的交换单元：`起势 → 位移 → 接触/落空 → 反应 → 定格尾帧`。
- **动作状态机闭环 (Action State Machine)**：交互动作必须有始有终（如接打电话必须有“拿起听筒 ➔ 通话 ➔ 咔哒一声将听筒扣回底座挂断”的动作闭环）。
- **换装跳切剪辑铁律 (Match Cut Transition)**：严禁在同一连续镜头内通过扩散模型渐变换装（例如睡衣变重铠）。变装必须在动作状态闭环后，采用硬切（Hard Cut）或匹配剪辑（Match Cut）转入全副武装的全新镜头。
- **刚体防回弹物理负向**：每个单元写清发力主体、清晰起点/路径/终点、受力反应与 **Anti-Bounce 刚体防回弹物理负向约束**。

### 3.9 草图转镜头（sketch_to_shot_brief）
草图只锁构图和关系，不直接锁人物脸或材质。必须由资产合同补齐外观与细节。

### 3.10 失败诊断与最小变量修复原则（Failure Attribution & Minimal Delta · Hell Grind）★
生成失败或质感崩溃时，严禁盲目重新抽卡或推倒重写整个提示词。必须按七层架构严格定位责任层，并执行最小变量修复：
- **脸崩/服装变样/伤痕消失** ➔ **L2 资产层** 责任：仅补充当前资产状态版本（State Versioning），特写核查是否绑定局部微距资产卡；
- **背景漂移/多出第三人/道具凭空出现** ➔ **L3 空间层** 责任：仅强化屏幕绝对坐标与第0秒刚体地标，增加人数与无中生有排他约束；
- **肢体融化/动作抽搐/换装失败** ➔ **L4 动作层** 责任：动词过载或试图单镜头变装，缩减动作幅度，换装强制拆镜头硬切；
- **背景像果汁般扭曲/空间塌陷** ➔ **L5 摄影层** 责任：运镜出现了复合多轴运动，立即降级为“单一轴向主运镜（Single-Axis Move）”；
- **声音夺舍/张冠李戴/未见先知** ➔ **L6 声画因果层** 责任：执行发声者机位主控 + 同画幅非发声者嘴部闭合死锁，按先动作后视线再发问重排序微时序；
- **【强制拆镜铁律 (Split-Shot Rule)】**：同一个镜头在定位责任层后，若连续 2 个批次（2 Takes）仍无法解决，判定为单个镜头内物理信息与动力学过载，**禁止继续抽卡，强制拆分为 2 个更短的单一动作子镜头**！

## 4. 提示词装配与协议编译（Higgsfield / Hell Grind 工业级标准）

将所有合同信息编译为前置锁死、微时序清晰的工业级提示词结构：

```text
integrated_multimodal_description:
【Master Rig & Visual Prefix | 前置锁死层】
[变形宽银幕焦段 / 胶片色彩管线 / 基础光影调性 / 全局建筑与环境 100% 静态刚体几何约束]

【Spatial Coordinates & Rigid Anchors | 空间绝对坐标与刚性地标】
- 屏幕绝对坐标分布（screen-left / screen-center / screen-right）
- 1~2 个固定刚性几何参照物（壁炉、石阶、断壁、机械齿轮）
- 稍后交互道具第 0 秒客观常驻声明（如地面半埋生锈齿轮）
- 接触面物理咬合纪律（鞋底钉死地面、手柄握持贴合）

【Kinematic Beat Timeline & Action | 动作微时钟与单一主运镜】
- [00:00.000 - 00:05.000 | 景别焦段 | 单一主运镜 (或 Static Hold)]:
  Open State (开场姿态与视线继承) ➔ 动作触发 ➔ 倾听者嘴唇紧闭 (lips pressed shut)
- [00:05.000 - 00:10.500 | 景别焦段 | 动作驱动单一轴向推/摇]:
  说话者占领主画框 ➔ 不可变台词口型匹配 <d>[Language] ...</d> ➔ 声线锁定 <Audio N>
- [00:10.500 - 00:15.000 | 景别焦段 | 定格静止锁定]:
  动作闭环完成（如听筒扣入基座） ➔ Close State (最终姿态定格，与 Picture 2 / 下段 Picture 1 咬合)

【Negative & Rigidity Constraints | 绝对排他与物理禁止项】
[严格人数限定、严禁多轴复合运镜、严禁滑步悬空、严禁背景几何变形、同画幅非说话者严禁张嘴动作、严禁中途虚空生成道具]

overall_soundscape:
现场物理碰撞 Foley 音效、环境背景声（暴雨、蒸汽、金属轰鸣、喘息、电话扣落清脆咔哒声）。

non_diegetic_music:
SILENT
```

## 5. 生成前 15 项工业硬门禁（Gate Checks · 工业十五项全能门禁）

只有同时满足下列全部条件，才输出 `ready_for_prompt` 并允许提交生成：

- [ ] **【前置锁死门禁】** 提示词首行已置顶 Master Rig Prefix，锁定焦段、光影色调与静态建筑几何刚性
- [ ] **【空间地标门禁】** 具备 2D 屏幕绝对坐标（screen-left/right）并包含 1~2 个具象刚性几何地标
- [ ] **【零秒常驻门禁】** 镜头中途被拾取/交互的道具，已在 00:00.000 作为客观刚体常驻场景坐标，严禁中途虚空生成
- [ ] **【单运镜门禁】** 每个微时序切片内严格执行单一主运镜，无多轴复合运镜冲突
- [ ] **【动作闭环门禁】** 交互动作具备完整生命周期（拿起-使用-放下/挂断），具有明确的结束态
- [ ] **【换装跳切门禁】** 角色更衣/换上重甲已拆分为独立镜头并使用硬切（Match Cut），绝不单镜头渐变换装
- [ ] **【时序因果门禁】** 台词严格落在“动作触发完成”与“倾听者视线注视反馈”之后，绝无未见先知的超前台词
- [ ] **【闭嘴死锁门禁】** 说话者占据主画框，同画幅非说话角色已显式声明“lips tightly pressed shut, silent listener”
- [ ] **【资产粒度门禁】** 特写与微距镜头已绑定专属局部微距资产卡，显式锁死拍摄法线并约束周边正常皮肤不异变
- [ ] **【闭环状态门禁】** 明确标注 Open State 与 Close State，实现尾首帧物理级咬合
- [ ] **【声线门禁】** 出场说话角色的专属 WAV 声线文件已在本地就绪，且在提示词中正确指派 `<Audio N>`，非主角声学隔离
- [ ] **【台词门禁】** 台词 100% 逐字匹配剧本不可变台账，口型可见性已通过校验（面部可见或声明画外）
- [ ] **【配乐门禁】** `non_diegetic_music` 严格锁定为 `SILENT`，无生成模型自造背景音乐
- [ ] **【调度与轴线门禁】** 调度图锁定 180° 轴线，摄影机与角色世界坐标一致，绝不跳轴
- [ ] **【接触物理门禁】** 脚底接触地面包含 Anti-Slide 防滑步约束，手部握持无穿模风险
- [ ] **【串行接力门禁】** 串行接力已锁定上一段 `-0.35s` 稳定尾帧为 `<Picture 1>`

任何一项不达标，必须退回对应责任层修复，严禁跳步生成。
